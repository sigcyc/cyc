# Change: add filter to cyc.cut

In `cyc/data_frame_monkey_patch.py:Cyc.cut`, add an argument `f`.

`f` is a boolean predicate. Rows where `f` is true are cut into bins as usual;
rows where `f` is false do **not** get dropped — the result keeps the same
length as the input series, so `cut` can be used inside `with_columns`.

Values excluded by `f` are routed to a dedicated `filtered` bucket. This
bucket is given a `NaN` breakpoint so it sorts **last** in `sort_cut`, after
every real bin.

`f` defaults to `True` (keep everything), which keeps the no-filter case on the
same code path — no branch.

Write tests to make it work, especially `sort_cut`.
